## DX12Project - 基于 DirectX 12 的 3D FPS 小游戏
本项目是游戏工程课程的编程作业，基于原生 DirectX 12 开发的轻量级 3D FPS 小游戏，核心目标是落地 3D 图形学经典技术（Gerstner 波、实例化渲染、法线贴图等），并掌握 DX12 的底层渲染架构设计与性能优化思路。

## 技术栈

编程语言: C++ (C++17及以上)                                                         
图形API: DirectX 12 (DX12)                                                         
开发工具: Visual Studio 2022 (需安装Windows SDK 10.0.19041.0+)                      
核心技术: DX12根签名/PSO、Gerstner波顶点动画、硬件实例化渲染、切线空间法线贴图、Alpha测试、第一人称相机物理 

## 核心功能
### 1. DX12底层渲染核心
- 分层架构设计：Core（DX12设备/交换链/根签名初始化）+ Window（窗口/输入管理）+ World（游戏逻辑总控）
- 根签名/PSO管理：自定义6槽位根签名，按着色器/功能模块隔离资源；PSOManager缓存渲染管线状态，提升绑定效率
- 常量缓冲区（CBV）/纹理缓冲区（SRV）：自动化更新逻辑，支持静态网格/实例化/动画/水面/光照多模块资源绑定

### 2. 3D图形学核心技术
- 水面顶点动画：基于Gerstner波实现程序化动态水面，支持顶点位置+法向实时更新
- 硬件实例化渲染：树木批量渲染（一次Draw调用绘制百级实例），大幅降低DrawCall开销
- 法线贴图：切线空间→世界空间转换（TBN矩阵），实现模型表面精细化凹凸纹理效果
- 透明效果：Alpha测试实现柳树叶子硬透明，兼顾性能与视觉效果
- 天空盒：球体承载HDRI全景纹理，模拟无限远天空背景

### 3. 游戏功能模块
- 第一人称相机：四元数旋转（无万向节死锁）+ 键鼠控制（WASD移动/鼠标视角/空格跳跃）+ 基础物理（重力/地面检测）
- 碰撞系统：支持AABB/OBB/球体碰撞，实现滑动碰撞响应，提升移动流畅性
- 动画状态机：基础状态管理（Idle/换弹），支持动画状态切换与播放控制
- 多关卡框架：支持关卡加载/重载，基础存档/读档能力

## 运行步骤
1. 打开项目：双击DX12Project.sln
2. 编译运行：点击 VS 工具栏-本地Windows调试器，编译完成后自动启动游戏

##  项目结构
```plaintext
DX12Project/
├── Core/                # DX12底层核心模块（设备/交换链/根签名/PSO）
│   ├── Core.h/cpp       # DX12初始化入口
│   ├── PSOManager.h/cpp # PSO创建与缓存管理
│   └── Pipeline.h/cpp   # 渲染管线封装（PSO+缓冲区）
├── Window/              # 窗口与输入管理
│   └── Window.h/cpp     # Windows窗口创建/消息循环
├── World/               # 游戏逻辑总控
│   ├── World.h/cpp      # 单例逻辑管理（关卡/渲染调度）
│   ├── Level.h/cpp      # 关卡管理（加载/保存/Actor管理）
│   └── Collision.h/cpp  # 碰撞检测与响应
├── Actor/               # 游戏对象（玩家/树木/水面/鸭子）
│   ├── Actor.h/cpp      # 基类（生命周期/绘制/碰撞）
│   ├── Player.h/cpp     # 第一人称玩家（相机/物理/动画）
│   └── StaticMesh.h/cpp # 静态网格（树木/地面/天空盒）
├── Shaders/             # HLSL着色器
│   ├── VertexShader.hlsl# 顶点着色器（实例化/动画/水面）
│   └── PixelShader.hlsl # 像素着色器（法线贴图/Alpha测试/光照）
├── Resources/           # 资源文件（模型/纹理/HDRI）
└── DX12Project.sln      # VS解决方案文件
```
## 核心技术亮点
- DX12 根签名 / PSO 设计: 通过宏定义匹配特定的CBV，兼容多种着色器绘制
- Gerstner 波水面动画: 程序化生成动态水面，无需动画资产，体现顶点动画实现思路
- 实例化渲染: 百级树木实例一次 Draw 调用完成，大幅降低 CPU 指令开销
- 四元数相机旋转: 避免欧拉角万向节死锁，实现第一人称自由视角，提升操作流畅性
- 滑动碰撞响应: 解决传统碰撞 “卡住” 问题，贴合 FPS 游戏移动手感需求

## 已知问题
1. 关卡重载崩溃：Actor 裸指针 + GC 不彻底导致野指针访问
2. 相机漂浮：关卡重载未重置地面检测状态，需按空格触发重力生效
3. 部分网格法向错误：模型法向烘焙 / 解析异常，导致光照渲染明暗错误
4. 加载速度慢：无资源缓存 + 同步加载，启动 / 重载关卡耗时较长
